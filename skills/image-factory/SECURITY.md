# 隐私和安全边界

公开包采用文件白名单导出，不包含来源仓库的 Git 历史、个人角色、照片、私有服务、真实商品、API 凭证或云存储配置。生成产物默认放用户的产品目录。

生图由宿主或用户配置的工具执行。不要把 Key、token、cookie 放进 brief、参考图说明、示例、仓库、图片、命令参数或聊天。请在相应工具的用户级配置中管理；撤销或轮换在服务商和用户工具配置中完成。

文件检查拒绝不同内容覆盖、符号链接图片和损坏图片。视觉审核由 Agent/用户完成，尺寸与哈希检查不证明文字、营销事实或平台审核通过。

发现疑似泄露请不要在公开 Issue 贴凭证原文，只报告文件位置和问题类型。发布扫描只报告路径和命中类型，不打印内容。扫描是辅助检查，不等于证明不存在所有可能的敏感信息。

API 适配器只接受 HTTPS，不跟随重定向、不自动重试。Key 从隐藏输入或 IMAGE_FACTORY_API_KEY 读取，不保存；错误不回显服务商响应正文。自定义地址由用户确认，使用专属于该服务的 Key。实际请求上传提示词和参考图，费用归用户账号；不要上传未授权或敏感素材。
