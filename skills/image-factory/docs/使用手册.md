# 图片工厂：商品海报使用手册

商品上架需要一套主图、详情图和营销海报。图片工厂把产品文案、版式和图片要求整理成可复用流程，让 Agent 按统一风格实际出图，再把文件交给上架清单。

## 第一步：安装

仓库：https://github.com/wukongai/image-factory-public

在终端执行，或让 Agent 帮你安装：

```bash
npx skills add wukongai/image-factory-public --skill image-factory
```

按提示选择当前使用的 Agent。只装到要使用的项目即可；已有同名私有 Skill 时，不要覆盖它。

电脑需要 Python 3.10+。让 Agent 在合适的目录建立虚拟环境，用虚拟环境的 Python 安装 Skill 目录里的 requirements.txt，然后用同一个 Python 运行脚本。示例：

```bash
python3 -m venv .venv-image-factory
.venv-image-factory/bin/python -m pip install -r <Skill安装目录>/requirements.txt
```

第一行建立隔离环境；第二行安装 Pillow。将尖括号替换为真实安装路径，Windows 的 Python 位于该环境的 Scripts 目录。

## 第二步：准备产品资料

提供四项：产品介绍与已确认卖点、需要的图片清单、后台尺寸要求、风格或授权参考图。没有设计模板也能做，先从内置方形主图和竖版详情模板开始。

产品价格、权益、效果、资质和评价不能凭空生成。资料不足时先补齐，不把不确定内容放进海报。

## 第三步：让 Agent 实际出图

```text
用 image-factory 为这个产品制作一套上架图片。
产品资料：[文件位置]
图片任务：1张方形主图、2张竖版详情图。
后台要求：[截图或尺寸]
风格：暖白背景、深蓝文字、橙色点缀，保持字体气质和产品外观一致。
输出目录：[当前产品的图片文件夹]
先整理每张图的标题、卖点和画面，再生成首图供我看。
确认后继续生成后续图片，并逐张检查中文、尺寸和内容。
请交付真实 PNG 和图片回执，不要只交提示词。
```

**生图工具用你自己的。**

- Agent 有内置生图工具：直接使用，不需要作者的 API。
- 你已接入生图 API 或 MCP：让 Agent 使用该工具；Key 在你自己的工具配置中管理，费用归你的账号。付费调用需你授权。
- 两者都没有：只能先生成提示词和交接文件；Agent 必须明确说明图片尚未生成。请先给 Agent 配好真实生图工具再继续。

本仓库不附带私人 Router，也不要求你访问作者的服务。它不提供独立的 HTTP 生图客户端；“用自己的 API”指 Agent 调用你配置好的工具。

## 第四步：与小店 Skill 一起用

再安装小店上架 Skill：

```bash
npx skills add wukongai/store-listing-kit --skill store-listing-kit
```

然后说：

```text
用 store-listing-kit 为这个产品准备上架素材。
图片任务调用 image-factory，使用我已配置的生图工具。
通过检查的 PNG 保存到当前产品的 04-商品展示与介绍目录。
把实际文件加入 HTML 交接清单，按后台顺序排列。
```

流程是：小店 Skill 整理资料与图片任务 → 图片工厂制作并检查 → 图片路径回交小店 Skill → 生成 HTML 清单。

打开 `打开这里.html` 或 `00-后台上传TODO.html`，按顺序复制文案、预览图片、复制文件路径后上传，完成一项勾选一项。清单不代替平台审核；目前不会自动登录和发布商品。

## 换风格、改尺寸和复用

告诉 Agent 更换配色、版式或画幅；它会复制 JSON 模板并调整 layout、constraints 和 size。要复用整套效果，可保存你自己的模板和第一张通过检查的参考图。不要把仅改变尺寸当作完成方形与竖版的排版适配。

只复制构图规则不能自动获得原海报品牌、人物或商品素材的使用权。参考素材应当是你自己的或已获授权的；本包没有作者私人 IP。

## 常见问题

- **只拿到提示词**：说明还没执行真实生图，检查当前 Agent 是否有可用图片工具。
- **尺寸被拒绝**：按后台尺寸重生，不把图片强行拉伸到目标比例。默认接受同画幅且不低于目标分辨率的原图；后台要求精确像素时，让 Agent 使用 --exact-size 检查。
- **文字不准确**：修改文案后重生对应图片，不把生成图里的错误当作产品事实。
- **覆盖被拒绝**：已有文件内容不同，用新的版本文件名；原图保留。
- **HTML 中图片打不开**：整体保留素材文件夹，清单使用包内相对路径，不要只转发一个 HTML。
