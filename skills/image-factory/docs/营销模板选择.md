# 营销海报模板怎么选

先选营销诉求，再选风格。同一风格提供方形主图（1:1）和竖版海报（2:3），避免整套图片只有配色一致、构图却不适配。

| 风格 | 适合什么 | 方图模板 | 竖版模板 |
|---|---|---|---|
| 黑底赛博大字 | AI 工具、科技产品、效率课程、发布与招募 | `cyber-bold-main-v1` | `cyber-bold-poster-v1` |
| 黑白大字冲击 | 知识产品、观点型营销、活动招募、强结果主张 | `type-impact-main-v1` | `type-impact-poster-v1` |
| 橙色活力转化 | 新品发布、课程招募、活动海报、促销（仅使用已确认优惠） | `orange-promo-main-v1` | `orange-promo-poster-v1` |
| 奶油质感高级 | 专业服务、咨询、精品课程、长期学习产品 | `cream-premium-main-v1` | `cream-premium-poster-v1` |

默认通用模板仍保留：product-main-v1、product-detail-v1、marketing-poster-conversion-v1、poster-reference-remix-v1。合计 12 个模板。

## 直接这样说

```text
用图片工厂的黑底赛博大字风，为这款 AI 产品做一张方形主图和两张竖版营销海报。
标题要大，背景近黑，电光青强调一个关键词。整套保留同一字体、配色和产品外观。
产品资料：[资料位置]
输出目录：[产品素材目录]
```

Agent 选择对应模板，填入确认文案后编译，再调用用户自己的生图工具实际出图。换成“黑白大字冲击”“橙色活力转化”或“奶油质感高级”即可切换风格。

促销模板只改变视觉表达；没有确认过的价格、优惠、名额或截止时间不能生成。
